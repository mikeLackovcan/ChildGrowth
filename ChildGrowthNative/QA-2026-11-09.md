## Reusable live tests

Run only on already-linked, disposable QA accounts. Both scripts modify live test data. The consent script temporarily disconnects and restores the QA family and respects the server's 61-second invitation cooldowns. Never run on personal family accounts.

Set these environment variables without committing credentials:

- `QUESTBLOX_LIVE_TEST=disposable-accounts-only`
- `QUESTBLOX_QA_PARENT_EMAIL`
- `QUESTBLOX_QA_CHILD_EMAIL`
- `QUESTBLOX_QA_PASSWORD`

Then run `node scripts/test-live-parent-child.cjs` or `node scripts/test-live-family-consent.cjs` from ChildGrowthNative. Parent/child test creates a unique temporary quest and removes it in a finally block. Consent test restores the accepted link in a finally block. Interrupted processes or network failures can still require manual QA cleanup.
