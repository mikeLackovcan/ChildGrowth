# Quest Champ generated world artwork

`quest-champ-town-board-v1.jpg` is an original generated background created for
Quest Champ's interactive My World canvas on October 25, 2026. It intentionally
contains no text, mascot, buildings, currency, UI controls, or third-party marks.
Interactive buildings, plot targets, and Quest Champ remain separate React Native
layers so the town stays playable and accessible.

The production file is a quality-86 JPEG (1082 × 1454, approximately 540 KB),
derived from the lossless generated PNG. The prompt requested a child-friendly
2.5D floating island with cream paths, a central fountain, open lawns, blue/lime
Quest Champ accents, and explicitly excluded Lego-, Roblox-, and brick-toy-like
styling.

## Town board v2 and original building family

`quest-champ-town-board-v2.jpg` and the eight transparent PNG files in
`original-buildings/` were generated for Quest Champ with OpenAI's built-in
image-generation tool on October 27, 2026. The board keeps the floating-island
direction but provides exactly ten unobstructed oval lawns connected by paths.
It contains no buildings, characters, vehicles, plot icons, text, currency,
logos, or UI. Existing plot IDs remain live React Native layers over the lawns,
so saved towns continue to load.

The original 512 × 512 RGBA placeable set contains `home.png`, `park.png`,
`bakery.png`, `school.png`, `library.png`, `clubhouse.png`, `cafe.png`, and
`studio.png`. Each sprite is a complete, centered, three-quarter isometric object
with transparent margins, cheerful upper-left daylight, soft contact shadow,
rounded fantasy architecture, and a palette matched to the board. The shared
prompt explicitly excluded people, mascots, text, letters, numbers, logos,
roads, borders, watermarks, cropped edges, and large concrete platforms. Each
subject prompt then described only the relevant child-readable landmark (for
example the blue-roof home, coral-awning bakery, turreted clubhouse, or compact
park). These are original Quest Champ assets rather than KayKit replacements or
reskins. Small planters, benches, and streetlights continue to use the recorded
CC0 KayKit source until matching original decoration assets are produced.
