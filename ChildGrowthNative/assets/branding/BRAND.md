# Quest Habi brand

Quest Habi is a friendly habit-and-chore companion for children. Everyday responsibilities become short quests, while Habi reacts, celebrates progress, and helps children know what to do next.

## Core palette

- Habi blue: `#2563EB`
- Friendly sky: `#38BDF8`
- Quest lime: `#B8F23D`
- Reward gold: `#F9B233`
- Warm coral: `#FF6B6B`
- Ink navy: `#132447`

## Assets

- `questpip-mark.svg` — editable source mark
- `questpip-icon-1024.png` — launcher icon source
- `questpip-play-512.png` — Google Play icon
- `questpip-adaptive.png` — Android adaptive foreground
- `questpip-monochrome.png` — Android themed icon
- `questpip-favicon.png` — web favicon
- `google-play-feature-graphic.png` — 1024 × 500 adventure artwork (no old wordmark)

The `questpip-*` filenames are retained as internal migration names. The customer-facing brand is Quest Habi.

## Store positioning

Short description: **Habits and chores become fun daily quests for kids.**

Long description: **Quest Habi helps children build routines through simple visual quests. Kids complete chores, homework, focus sessions, and healthy habits; Habi celebrates their progress with coins, XP, character items, and family rewards. Parents can create quests, choose reminders, review progress, and link securely with a child account.**
