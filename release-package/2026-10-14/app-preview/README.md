# Quest Hero app design concept

Generated visual exploration using the built-in image tool. Not a real app screenshot and not suitable as a Google Play screenshot. No application code was changed for this preview. Exact prompt: prompt.txt. Image: quest-hero-app-concept.png.

The proposal applies cobalt, lime, navy and warm ivory to daily quests, task creation and prize history. It uses the selected hero in encouragement and progress cards. Example names, balances and tasks are illustrative, not user data.

Existing functionality referenced: daily tasks and completion, habit icons, recurring schedules, optional parent approval, earned XP/levels, prize history and claimed states.

Proposed layout changes beyond colors: a compact header, larger task targets, a fixed creation button, and a three-tab Quests / Prizes / Shop navigation that omits the unfinished Battle tab and moves supporting settings outside the primary navigation. These changes require implementation and Android verification. Category grouping and illustrative copy are proposals; not claims of a shipped feature.
