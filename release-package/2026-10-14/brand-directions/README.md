# QuestBlox — three brand directions

Concept boards generated with the built-in image tool. These are previews, not final production icon exports or trademark clearance. The app was not changed by this exploration.

- 01-quest-hero.png: the selected friendly hero, cobalt/lime, adventure-led.
- 02-quest-crew.png: original duo, teal/coral, cooperation-led.
- 03-level-up-q.png: geometric Q/check symbol, purple/mint, progress-led.

The original prompts are in prompts.json. For boards 02 and 03, a follow-up edit preserved all icon artwork and wording while replacing dark/transparent presentation backgrounds with opaque warm ivory and increasing text contrast. Generated swatches are indicative; production colors should use the specified hex values in prompts.json.

Recommended starting point: Quest Hero, since it retains the character direction selected by the owner. Quest Crew communicates family teamwork; Level-Up Q is the simplest silhouette for a small launcher icon.
