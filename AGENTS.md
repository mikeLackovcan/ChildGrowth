# Questblox translations

For every Questblox user-facing change, read and follow
[ChildGrowthNative/TRANSLATIONS.md](ChildGrowthNative/TRANSLATIONS.md).

Translations are a standing user requirement. Deliver English, Czech, Spanish,
and German together, including notifications, errors, and accessibility labels.
Keep child-facing wording short and visual. Translation checks and review of the
affected screens are part of each change, not a later task.

Also follow [ChildGrowthNative/AGENTS.md](ChildGrowthNative/AGENTS.md) when working
in the React Native app.
